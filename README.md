# Buraco — Dani & Bru

Caderneta digital com pontuação por rodada, correções, vul acima de 1.500 pontos e histórico online por data.

React/Vinext + Cloudflare Workers + D1. Node 22+. Instalação: `npm run install:ci`. Build: `npm run build`. Configure D1 com binding `DB` e aplique as migrações em `drizzle/`. Hospede com acesso privado: a caderneta é compartilhada pelos usuários autorizados na plataforma. O repositório contém somente código, nunca os placares. A gravação usa revisão para evitar sobrescritas entre abas.

A fonte Caveat é carregada pelo Google Fonts, com alternativas manuscritas locais. A partida é encerrada manualmente; empate é preservado. Em 1.500 exatos o jogador ainda não está vul.

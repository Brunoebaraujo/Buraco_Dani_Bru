# Buraco — Dani & Bru

Caderneta com pontuação por rodada, correções, partidas de 3.000 ou 5.000 pontos e vul a partir de 1.500 ou 2.500 pontos e histórico online por data.

React/Vinext + Cloudflare Workers + D1. Node 22+. Instalação: npm run install:ci. Build: npm run build. Configure D1 com binding DB e aplique as migrações em drizzle/. Hospede com acesso privado: a caderneta é compartilhada pelos usuários autorizados pela plataforma. O repositório contém somente código, nunca os placares. A gravação usa revisão para evitar sobrescritas entre abas.

A fonte Caveat é carregada pelo Google Fonts, com alternativas manuscritas locais. Encerramento manual; empates são preservados. O vul começa ao atingir metade da meta escolhida. Partidas antigas são interpretadas como 3.000 pontos. A meta é fixada ao anotar a primeira rodada e é preservada no histórico.
